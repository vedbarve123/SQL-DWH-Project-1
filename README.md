# SQL-DWH-Project-1
Welcome to my project.
Here I am building a Data Warehouse repository using SQL server. I am also going to generate actionable insights.

Objective:
Build a Data Warehouse using SQL Server to consolidate sales data , enabling analytical reporting and informed decision making.

Specifications:
Data Sources: Ingest data from 2 source systems CRM and ERP which are provided as CSV files.
Data Quality: Cleanse and resolve data quality issues prior to analysis.
Scope: Focus on latest dataset only . No Historizations.

Analysis:
Customer Behaviour
Product Performance
Sales Trends
